# Code of conduct

Arc welcomes contributors with different backgrounds and levels of experience.

- Treat people respectfully. Critique code and design with specific examples.
- Help newcomers understand the project and its constraints.
- Do not harass, threaten, discriminate, publish private information or spam.
- Respect maintainers' decisions about scope and release readiness.

Maintainers may remove inappropriate content or restrict participation to keep the project useful and welcoming. For a sensitive conduct concern, request a private conversation through the maintainer's GitHub profile without posting personal details publicly.
